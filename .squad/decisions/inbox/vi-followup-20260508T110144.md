Title: Convert speed fields to durations (proposal)

Context:
Some fields currently expose speed values that are ambiguous for integration and smoothing. Converting to explicit duration/interval values (or providing both) simplifies dt handling and smoothing logic.

Proposal:
- Replace 'speed' fields with 'duration' or add 'duration_ms' alongside speed where needed.
- Update nose dt propagation so downstream code uses explicit durations.
- Add tests to ensure backwards compatibility and migration notes.

Next steps:
- Open a focused PR to change field names and add migration helpers.
- Coordinate with frontend/consumers on naming.
